# Stellar Media — Final Candidate Landing Page

Built to match the task brief: one modern, responsive landing page for a marketing agency based in Abu Dhabi, UAE.

## Required sections included
- Hero section with headline and call-to-action
- About Us
- Services
- Client testimonials in a responsive slider/carousel (adapted from the supplied reference website)
- Contact

## Content reference
The supplied reference site, https://stellarmedia.co.za/, was used only as a content reference for agency messaging and testimonial structure. The page is still tailored to the task brief: an Abu Dhabi, UAE agency landing page for government entities and major brands. Testimonial snippets and attributions are adapted from the reference site and should be confirmed as approved for use before publication.

## Stack
- HTML5
- Custom CSS3
- Vanilla JavaScript
- Bootstrap 5 (responsive navigation/grid utilities only)
- Font Awesome icons
- No React, no Vite, no build step

## Project files
- `index.html` — page structure and copy
- `css/style.css` — complete visual system, responsive layout, typography and hover states
- `js/main.js` — loading screen, sticky navigation, active-section navigation, mobile menu closing, testimonial slider, scroll-to-top button, reveal animations, current year, contact form validation and mailto handling

## Run and publish
Open `index.html` in a browser. Internet access is needed for the Bootstrap CDN and Google Fonts. To publish, upload the files to a static host such as Netlify or Vercel; no build command is needed.
